💬 常見問題
免費方案會過期嗎？
不會。免費方案可以永久使用，每天 10 次轉換，無時間限制。
轉換次數如何計算？
每次點擊「開始轉換」算一次，不論文字長度或引擎選擇。API 模式下的轉換使用你自己的 API Key。
我的 API Key 安全嗎？
非常安全。API Key 僅在你瀏覽器本地儲存（localStorage），不會上傳到我們的伺服器。也可留空使用後端環境變數。
支援哪些電子書格式？
支援 EPUB、PDF、DOCX 直接在瀏覽器內解析。Mobi 和 Azw3 格式需要轉換後上傳。
方案升級 / 降級？
直接在頁面上切換方案即可。即將支援線上升級功能，詳見更新公告。
我可以自訂聲音嗎？
ElevenLabs 支援聲音克隆（需帳號設定）。其他引擎使用預設聲音，即將支援聲音上傳。

準備好開始了嗎？

免費方案無需註冊，立即使用瀏覽器內建語音。
